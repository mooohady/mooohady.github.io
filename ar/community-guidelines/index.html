إرشادات المجتمع

احمِ الناس والحيوانات. يُمنع التهديد والمضايقة والتتبع والتشهير وكشف المعلومات الخاصة والقسوة والإهمال والقتال والتسميم والهجر والتزاوج القسري والممارسات الطبية الخطرة والاتجار غير القانوني.

كن صادقًا ومفيدًا. لا تنتحل شخصية أحد، ولا تُخفِ معلومات جوهرية عن الملكية أو الصحة، ولا تنفذ عمليات احتيال أو رسائل متكررة أو روابط خادعة. شارك فقط المحتوى الذي تملك حق استخدامه.

احفظ البيانات الحساسة. لا تنشر عنوان المنزل الدقيق أو بيانات التواصل الخاصة أو مستندات الهوية أو بيانات الدفع أو السجلات الطبية أو بيانات شخص آخر.

يمكنك الإبلاغ عن المحتوى أو الحساب وحظر المستخدم فورًا. نراجع المعلومات المتاحة ونحفظ الأدلة الضرورية مع تقييد الوصول إليها. قد نحذف المحتوى أو نوجّه تحذيرًا أو نقيّد الميزات أو نوقف الحساب مؤقتًا أو نغلقه، وقد لا نتخذ إجراءً إذا لم يثبت وجود مخالفة. نعطي الأولوية لبلاغات الخطر العاجل، وقد نحيلها إلى الجهة المختصة وفق القانون. البلاغ لا يعني تلقائيًا ثبوت المخالفة. نوضح سبب القرار ونتيح الاعتراض عليه، ما لم يمنع ذلك القانون أو يعرّض أحدًا للخطر.
